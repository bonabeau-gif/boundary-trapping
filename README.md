# Boundary trapping in information-geometric evolutionary closures

Reproducibility repository accompanying Eric Bonabeau's manuscript **Boundary trapping in information-geometric evolutionary closures**

## Installation

```bash
python -m venv .venv
source .venv/bin/activate              # Windows: .venv\Scripts\activate
python -m pip install -e '.[test]'
python -m pytest -q
```

## Reproduce results

```bash
MPLBACKEND=Agg python scripts/regenerate_core.py --output figures/generated
python scripts/classification_rate_check.py
```

* `src/boundary_trapping/`: reusable implementation of the circular wrapped-Cauchy dynamics, ordinary Cauchy–Lorentzian example, dimension-four spherical harmonic factors and two uniform-reset closure models.
* `tests/`: exact-limit, Fourier, harmonic-gradient, conservation-law, moment-hierarchy, boundary, mutation and numerical-integral checks.
* `scripts/regenerate_core.py`: **six independently regenerated core verification figures** from explicit model equations, with a fixed Monte Carlo seed. These are verification figures, not pixel-identical copies of the corresponding manuscript panels.
* `scripts/classification_rate_check.py`: author's supplied anisotropic Morse/Hessian exponent validation, including a slow dimension-three hypergeometric continuation.
* `figures/published_reference/`: the **ten source images embedded in the latest Word manuscript**, extracted without alteration, for visual reference. They are **not regenerated by `regenerate_core.py`**. The embedded filenames are Word media indices, **not verified figure-number mappings**.
* `legacy/`: original scripts from the earlier eight-figure reproducibility archive, included intact for provenance, not claimed as a consolidated reproducibility runner for the final manuscript.
* `manuscript/`: the exact final supplied Word manuscript with Morse classification. No algorithm depends on Word/LibreOffice.

## Important reproducibility boundary

The numerical results support *checks of particular formulas*, not automated formal proofs of the almost-everywhere Morse theorem, boundary classification, or general hyperbolic estimates. The manuscript is the source for hypotheses and proof statements.

## Conventions

For `circle.py`, `z=u+iv` and `f(theta)=c0+Re(sum(A[k-1]*exp(ik theta)))`. With this convention, `E[exp(i k theta)] = z**k`, expected fitness is `c0+Re(sum(A[k-1]*z**k))`, and the physical-time Fisher velocity is `(1-|z|²)² grad(J)/2`. In `spherical.py`, ambient dimension is four. Mutation rate conventions follow the manuscript's uniform-reset operator.

## Running on GitHub

Create a new repository and upload the extracted contents. The `.github/workflows/ci.yml` workflow tests Python 3.10 and 3.12 and regenerates the core figures in a noninteractive environment. No tokens, cloud services, private datasets or proprietary dependencies are required.

## Additional symmetric-phenotype control

`src/boundary_trapping/watson.py` implements the Watson-type exponential family for antipodal selection and the deterministic projected angular-diffusion / reset equations. Its normalization and Bessel moment identity are covered by an automated derivative test.
